# Tatum AI Builder (Part 15)

The Total Recall form has an optional item: "Optional build with Tatum AI Builder (ai.tatum.io) for the dedicated $500 bonus". Eranos enters it, with this disclosure so the judges can weigh it fairly.

## What was done on ai.tatum.io

The prompt below was run on ai.tatum.io on 10 Nov 2026 by Kinnoski, producing a project called "Sui Savings Circle App" in the Tatum dashboard (AI Builder, beta). It generates a first Next.js shell with the pages named in the prompt.

```text
Build a mobile-first Next.js app called Eranos: a savings circle (tanda, ajo, susu) on Sui. Members
connect a Sui wallet, see a ring of members with whose turn it is, pay their round in USDC, and see
a timeline of rounds. Include pages: landing, my circles, circle home, memory (known, heard,
keeper), stewards (proposals to sign), proof. Use Tatum Sui RPC for all chain reads, and leave
clean hooks for Walrus Memory (@mysten-incubation/memwal) remember and recall. Light blue Sui
colours, serif accent headlines, no emoji.
```

## What was not done on ai.tatum.io

The shipped Eranos (the Move contract, the keeper, x402, the memory policy, the planner, the live circle and every mainnet transaction) was written in a terminal with Claude Code, not with ai.tatum.io. The AI Builder run supplied the page scope; the code in this repository does not descend from its export. We therefore do **not** claim the product was built "primarily" with ai.tatum.io. We enter the award on the optional-item basis and leave the judgement to the judges.
